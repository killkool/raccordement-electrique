    Infos complémentaires

    Code couleur des fils

    Rappel NF C 15-100. Bleu et vert/jaune sont réservés. Les autres couleurs sont libres — y compris sur un câble préfilé.

    Bleu Neutre — obligatoire
    Vert / jaune Terre — obligatoire
    Rouge En général la phase
    Noir ou gris Souvent fil pilote radiateur
    Autres Navettes, retour lampe, commande

    Câble préfilé 5G (marron, rouge, noir, bleu, vert/jaune) : conforme pour un télérupteur si bleu = neutre, vert/jaune = terre, et que vous notez clairement rouge = retour lampes, noir = commande poussoirs (ou l’inverse, mais partout pareil).

    Couleurs usuelles en logement neuf : phase marron, neutre bleu, terre vert/jaune. Orange, noir, gris, violet, rouge, rose, blanc sont libres (jamais bleu ni vert/jaune pour autre chose). Sur une rénovation, fiez-vous à la fonction si les couleurs diffèrent. Voir aussi le code couleur en bas de page.
